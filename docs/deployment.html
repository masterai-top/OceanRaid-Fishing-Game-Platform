Build and publish

Deployment starts with verification

Public scaffold checks

  • Python 3.11+: install server-python/.[dev], run Ruff and pytest.
  • CMake 3.20+ and C++17: configure, build and run CTest under server-cpp/.
  • Node.js 20+: install, syntax-check and test admin/.
  • On Windows, ./scripts/validate.ps1 runs the combined checks.

Passing these checks validates the public 0.1.0 scaffolds only. It does not establish a complete production client or historical backend.

Publish documentation

  1. Upload docs/ and .github/workflows/pages.yml.
  2. Open Settings → Pages and choose GitHub Actions.
  3. Push to main and confirm Deploy documentation to GitHub Pages succeeds in Actions.
  4. Open the Pages URL and verify all images and pages.

Production gate

Complete clean builds, secrets scanning, dependency review, database migration, load testing, monitoring, backup/restore, rollback, security, fairness, privacy, asset licensing and jurisdiction reviews before serving users.
