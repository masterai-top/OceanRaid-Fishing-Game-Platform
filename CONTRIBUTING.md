# Contributing

Before submitting a change, remove credentials, production data, player information, payment records, and third-party assets that cannot be redistributed. Keep changes focused and document the affected client, service, protocol, database, or admin module.

Pull requests should include the purpose, compatibility impact, test environment, validation results, and privacy-safe screenshots for visible changes. Protocol or database changes must describe migration and rollback requirements.

Run `./scripts/validate.ps1` on Windows, or execute the Python, CMake/CTest, Node.js, and repository-contract checks separately. Clearly distinguish scaffold changes from historical product or asset changes.

Contributors confirm that they have the right to submit their work and that it may be distributed under this repository's license terms.
