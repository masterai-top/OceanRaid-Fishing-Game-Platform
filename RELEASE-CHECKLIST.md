# Release Checklist

- Tag a reviewed commit and publish the exact source and asset inventory.
- State which components are production implementations and which remain scaffolds.
- Publish supported runtime, compiler, Cocos/Lua, database, and middleware versions.
- Include clean-build and test results, dependency locks or an SBOM, and artifact checksums.
- Remove secrets, production data, local paths, logs, caches, and unlicensed assets.
- Document database migrations, compatibility, backup, restore, upgrade, and rollback steps.
- Record known limitations and all unverified historical product claims.
- Complete security, fairness, privacy, licensing, and target-market reviews.
